## 📖 项目缘起

我们每天走过的路、居住的街巷、生活的县市，常常叠印着一段段尚未远去的民族记忆。

- 漫步北京，西城区并立着佟麟阁路与赵登禹路；
- 漫步天津海河之滨或武汉汉口江岸，张自忠路静静面迎江水与车流；
- 翻开中国地图，吉林有靖宇县，黑龙江有尚志市，山西有左权县，河北有黄骅市；
- 深入苏北里下河水乡，学富镇、特庸镇、瑞丰镇、明朗村，数十座乡镇以牺牲于此的新四军指战员之名世代相传；
- 追溯 1940 年代的解放区区划档案，还曾设立过宏毅县、包森县、紫石县、雪枫县、自忠县……

这些地名背后是一场战争，更是一代人。1931 年 9 月 18 日，日本发动侵华战争，战火从东北蔓延至全国，直到 1945 年日本战败投降。十四年间，无数将士与民众在侵略者的炮火下殉国，他们的名字随后被镌刻进山川道路、县市乡镇。

《山河同名》收录并呈现这些以殉国英烈命名的中国地名，用地图、编年时间轴与名录档案，把脚下的地名重新接回 1931—1945 年的历史时空。

> **战争名称与性质说明**：本档案所涉战争，国际史学界通称**第二次中日战争（Second Sino-Japanese War）**，中国通称**抗日战争（War of Resistance against Japanese Aggression）**。这是一场日本对中国的**侵略战争**——中文称「**日本侵华战争**」，英文称 *Japan's war of aggression against China*。对侵略与反侵略的认定，是本档案的立场起点。

## 🏛️ 三大核心视图

系统提供三种互相贯通的观察方式：

### 1. 碑林名录

以拓片般的版式罗列地名条目。今名与旧称对照，殉国英烈姓名、年龄与史料出处一并在列。没有繁复控件，只有纸色、墨色与朱砂色。

### 2. 编年史

按时间纵向展开 1931—1945 年的关键节点与英烈条目。时间轴从 1925 年五卅运动的前驱时代起，历经 1931 年九一八事变、1937 年卢沟桥事变与淞沪会战、1938 年武汉会战、1940 年百团大战、1942 年太行反扫荡，直至 1945 年抗战胜利与各地易名。「牺牲战役 → 命名更名」的因果链条清晰可见——例如 1940 年 2 月 23 日杨靖宇将军于濛江县殉国，1946 年濛江县更名靖宇县，沿用至今。

### 3. 山河地图

在全国地图上定位每一处地名。地图采用高德底图（按中国官方画法绘制国界），深色底图如砚台嵌于纸面装裱。左侧地图、右侧为可推拉的史料档案面板，专题街区以朱砂与墨线标出。

## 📊 收录规模

本档案现有 **294 处**以抗战英烈命名的地名记录，覆盖 **24 个省、自治区、直辖市**，涉及 **239 个英烈名号**（含以战斗集体立目者），共标注 **775 条**史料出处。按地名层级分：

- **现存县市（4 处）**：靖宇县（杨靖宇）、尚志市（赵尚志）、左权县（左权）、黄骅市（黄骅）。
- **历史曾用烈士县名（41 处）**：抗战时期或胜利后设立、后又并入现代区划的包森县、振堂县、企之县、宏毅县、麟阁县、筑先县、理琪县、登禹县、竹庭县、雪枫县、紫石县、自忠县、复程县、匡五县、南峰县、康杰县、士敏县等。
- **城市街道（74 处）**：北京佟麟阁路、赵登禹路、张自忠路；上海自忠路、晋元路、子青路；武汉张自忠路、郝梦龄路、陈怀民路、芦沟桥路；哈尔滨尚志大街、靖宇街、兆麟街；通化靖宇路、延吉德泰街、凤城邓铁梅路、苗可秀街。
- **乡镇与村落（175 处）**：苏北里下河水乡是全国最密集的新四军烈士命名乡镇带——学富镇、特庸镇、明朗村、泽夫村、合德镇、大中街道、振东村、白丁村、正红镇、黄尖镇；华北有河北献县本斋村、易县狼牙山镇、山东理琪村、耀南村、振华村；东北抗联则有敦化翰章乡、汪清振波村、铁力宏生村、富裕县绍文乡、肇东明久乡。

山河图层已定位 **252 处**；其余 **42 处**经纬尚未考订，它们照常收录于碑林名录与编年史，仅不出现在地图上，逐条原因见 [`scripts/data/pending_coordinates.md`](./scripts/data/pending_coordinates.md)。更名年份、生卒年与殉国日期缺载者同理，页面一律标注「待考」，不以推测填补。

我们不做「绝无讹误」的承诺——史料考据可以被继续推翻。编者自查确认的口径问题、建模缺陷与待核条目，公开列于 [`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md)；若你掌握更好的出处，欢迎据其勘误。

## 🔍 史料考据原则

1. **多重档案交叉印证**。每一条收录均核对《中华人民共和国地名大词典》、地方志（县志、区志）、抗战档案文献与退役军人事务部（原民政部）抗日英烈名录。
2. **不把推测当事实**。严格区分「因纪念某人而命名」与「历史事件发生于某地」；对英烈并未在此地出生或牺牲、仅因其功勋被当地命名的（如哈尔滨一曼街），明确注明命名缘由与沿革。
3. **忠实记录沿革与现代区划**。对解放战争及建国后撤销合并的历史烈士县（如冀东包森县并入遵化市、清河紫石县更名海安市），在档案中完整保留时代印记。
4. **收录标准是「命名行为」，不是「牺牲年份」**。本项目收录的是**因抗战英烈纪念而得名、且该名沿用至今或见于区划档案**的地名。因此个别记录的牺牲年份会越出 1931—1945——如顾正红 1925 年牺牲于五卅运动，其故里「正红镇」由新四军三师于 1943 年前后命名；李兆麟 1946 年遇害，哈尔滨兆麟街以其抗联功绩命名。**这不是数据错误**——把它们读成「1931—1945 英烈名录」才会产生误解（详见 [`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md) 第 2 条）。

## 🚀 快速开始

项目基于 Next.js 16，需要 **Node.js ≥ 20.9**。

```bash
# 1. 克隆仓库
git clone https://github.com/KirishimaEri/echoes-of-heroes.git
cd echoes-of-heroes

# 2. 安装依赖
npm install

# 3. 本地开发（Next 16 默认使用 Turbopack）
npm run dev
```

启动后访问 [http://localhost:3000](http://localhost:3000)。

构建、验证命令与工程细节见 [TECHNICAL.md](./TECHNICAL.md)。

## 🤝 参与贡献

我们深知个人的视野有限，而华夏山河辽阔。如果您在地方志、家乡档案、文史资料中发现尚未被系统收录的抗战英烈命名地名，热烈欢迎参与共建！

### 贡献标准

1. **必须有可查出处**：不接受自媒体段子、旅游软文与无署名转述。请给出文献名，能到卷/册/页更好——现有 311 条出处的最大短板正是无法点击核验（见 [`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md) 第 4 条），你的补充就是在补这个项目最大的弱点。
2. **区分「因纪念而命名」与「事件发生地」**：只有前者进主集合；后者如需收录，请在 PR 中说明，我们会评估是否单列。
3. **收录口径以命名时间为准**，不以牺牲年份是否在 1931–1945 内为准（详见「史料考据原则」第 4 条）。

### 数据字段与提交流程

⚠️ **不要直接改 `src/data/places.json`。** 它是生成产物，真源是按片区拆分的 `scripts/data/sector*.json`（基线 `sector1`–`sector5`，扩充 `sector6-northeast`、`sector7-north`、`sector8-east`、`sector9-centralsouth`、`sector10-west`）；任何人执行 `node scripts/merge_places.js` 都会用源文件整体覆盖 `places.json`。294 条扩充当初正是只写进了产物，才使一次合并几乎将其清空——现在 merge 在结果**少于**现有产物时会拒绝写入。

正确流程：

```bash
# 1. 把新记录加进它所属片区的 sector 源文件
# 2. 重新生成主数据文件（若结果比现有产物少，需 --force 才允许删减）
node scripts/merge_places.js
# 3. 门禁：类型 → 规范 → 视图模型与 epoch 不变量测试 → 数据不变量校验
npm run check
# 4. 构建后再校验导出与数据是否一致（首页计数 == places.json 条数）
npm run build && npm run verify:export
```

一条记录的完整字段（`merge_places.js` 强制 `id`、`modern_name`、`hero.name` 非空与 `id` 全库唯一，并把无法解析的 `coordinates` 归一为 `null`；年份值域、类别枚举、坐标轴序与重复记录由 `npm run validate:data` 把关）：

| 字段 | 含义 | 注意 |
| :--- | :--- | :--- |
| `id` | 稳定标识 | 建议 `省份-市-名` 的拉丁小写连字符形式，全库唯一 |
| `modern_name` | 今名 | |
| `former_name` | 旧称 | **不是** `historical_name` |
| `category` | `县市` / `街道` / `乡镇与村落` / `历史曾用县名` | 类型里还有个零使用的 `乡镇`，请勿新增使用 |
| `province` / `city` | 省级、市级归属 | 跨省用 `省A/省B`，两侧均为全称 |
| `coordinates` | **`[经度, 纬度]`**，未考订者写 `null` | 与 `thematics.ts` 的 `[纬度, 经度]` 相反，见 KNOWN_ISSUES 第 6 条；空数组不被接受，一律用 `null` 表示经纬待考 |
| `renamed_year` | 命名/更名年份 | |
| `hero.name` | 英烈姓名或集体称谓 | 群体条目请在命名中体现（如「…群体」「…群英」） |
| `hero.birth_year` / `death_year` / `sacrifice_age` | 生卒与殉国年龄 | 个人记录须满足 `death_year − birth_year = sacrifice_age`；群体条目为代表年岁，不适用该式 |
| `hero.title` / `force` / `sacrifice_date` / `battle` / `story` | 头衔、阵营、殉国时间地点与事迹 | `force` 暂无枚举白名单，新增同义词前先查现有取值 |
| `modern_status` | 今日地貌与使用状况 | |
| `sources` | 史料出处数组 | 每条一项，宁多勿缺 |

提交 Pull Request，或通过主页「点亮家乡英雄地名」入口留言均可；PR 优先，因为它能让出处留在可追溯的位置。勘误提交与署名要求见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

## 💻 技术说明

面向普通读者的简版；开发者请阅读 [TECHNICAL.md](./TECHNICAL.md)。

- **技术栈**：Next.js 16 · TypeScript · Tailwind CSS v4 · Leaflet / React Leaflet
- **部署形态**：纯静态导出，产物无服务端依赖，可托管于 GitHub Pages、Cloudflare Pages 或任意静态服务器，成本近乎为零。
- **离线能力**：名录与编年史视图离线可完整使用；地图底图瓦片为运行时网络请求，断网时地图区域为空白，但标记与档案数据仍来自本地。底图仅采用高德（按中国官方画法绘制国界），不提供境外瓦片源（原因见 [`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md) 第 5 条）。
